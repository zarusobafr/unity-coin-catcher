# 2D Coin Collector

A simple 2D coin-collecting game built with **Unity**.

## Gameplay Screenshot

![2D Coin Collector gameplay](Screenshots/gameplay.png)

## How to Play

-   Move the player horizontally.
-   Collect the falling coins.
-   Each collected coin increases your score.

## Built With

-   Unity
-   C#

## Project Structure

The Unity project files are organized into the following main folders:

-   `Assets/` --- Scenes, scripts, sprites, and other game assets.
-   `Packages/` --- Unity package dependencies.
-   `ProjectSettings/` --- Unity project configuration.

## Running the Project

1.  Clone or download this repository.
2.  Open Unity Hub.
3.  Select **Add** and choose the downloaded project folder.
4.  Open the project in Unity.
5.  Open the game scene and press **Play**.
